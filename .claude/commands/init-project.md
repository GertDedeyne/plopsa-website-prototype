Initialize the project:

1. Read all content in `project-inputs/` (documents, briefs, notes, data)

2. Produce a synthesis:
   - Context
   - Objectives
   - Expected deliverables
   - Constraints
   - Unclear areas

3. Ask clarifying questions about anything unclear

4. Update `PROJECT-STATUS.md` with the validated synthesis

5. Wait for user validation before any production work
